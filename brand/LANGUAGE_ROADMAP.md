# VIS Language Roadmap

## Purpose

This document defines the long-term internationalization strategy for
the official VIS website and the VIS platform.

The order of language support is determined by:

-   market size;
-   purchasing power;
-   commercial potential;
-   future partnerships;
-   international scalability.

# Localization Rules

Every language version must include:

-   translated interface
-   localized SEO
-   localized metadata
-   localized Open Graph
-   localized structured data
-   localized legal pages

No automatic machine translation should be published without review.

------------------------------------------------------------------------

# Platform Integration

The website language strategy must remain compatible with the future
centralized VIS multilingual architecture.

Website localization and platform localization should use the same
language identifiers and locale conventions.

------------------------------------------------------------------------

# Long-term Goal

VIS should become a globally available platform while preserving one
unified visual identity and one consistent product architecture across
all supported languages.
