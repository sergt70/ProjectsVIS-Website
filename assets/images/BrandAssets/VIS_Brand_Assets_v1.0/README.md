# VIS Brand Assets Pack v1.0

Official working asset package for VIS — Viral Intelligence System.

## Structure
- `01_Logo` — SVG master files
- `02_PNG` — raster exports
- `03_Favicons` — browser and app icons
- `04_OpenGraph` — social preview images
- `05_Brand_Documents` — approved brand documents
- `06_Colors` — official color palette
- `07_Typography` — typography guide
- `08_CSS_Tokens` — shared CSS variables

## Important
Use SVG files as the source of truth. Generate future raster copies from the approved SVG masters.
Do not stretch, rotate, recolor arbitrarily or redraw the official mark.
