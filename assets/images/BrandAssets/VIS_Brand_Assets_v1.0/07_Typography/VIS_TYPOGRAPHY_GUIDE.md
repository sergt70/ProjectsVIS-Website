# VIS Typography Guide v1.0

## Primary UI stack
`Poppins, Montserrat, Arial, Helvetica, sans-serif`

## Safe web fallback
`Arial, Helvetica, sans-serif`

## Recommended usage
- Display headings: 700
- Section headings: 600–700
- Body text: 400
- Labels and buttons: 500–600
- Technical metadata: 400–500

Use readable line height, restrained letter spacing and sufficient contrast.
