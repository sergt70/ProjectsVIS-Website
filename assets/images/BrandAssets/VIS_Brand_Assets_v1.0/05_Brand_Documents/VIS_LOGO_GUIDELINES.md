# VIS Logo Guidelines

**Version:** 1.0

## Purpose
Defines the official rules for using the VIS logo consistently across the website, platform, documentation and future products.

## Official Logo
The approved logo consists of:
- VIS geometric mark
- VIS wordmark
- Subtitle: Viral Intelligence System

## Logo Variants
- Primary
- Horizontal
- Vertical
- Mark only
- Monochrome dark
- Monochrome light

## Meaning
The symbol represents:
- Intelligence
- Structure
- Precision
- Growth
- Continuous improvement
- Reliability

## Clear Space
Keep free space around the logo equal to at least the height of the central diamond.

## Minimum Sizes
- Website header: 140 px
- Dashboard: 120 px
- Documentation: 35 mm
- Social avatar: Mark only
- Favicon: Mark only

## Color Usage
Primary:
- Deep Navy
- Gold / Amber

Monochrome versions are allowed when necessary.

## Backgrounds
Preferred:
- Dark
- White
- Neutral gray

Avoid busy backgrounds.

## Incorrect Usage
Do not:
- Stretch
- Rotate
- Recolor arbitrarily
- Add effects
- Change proportions
- Redraw the symbol

## File Formats
Master files:
- SVG
- PNG
- PDF
- ICO

## Governance
The logo is part of the VIS brand identity and should be used according to these guidelines.

**End of Version 1.0**
