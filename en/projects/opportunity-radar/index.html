Overview

From public opportunities to actionable leads

The system reduces repetitive marketplace monitoring by collecting public project data, applying deterministic filters and AI-assisted analysis, and presenting relevant opportunities in a structured Telegram workflow.

Multi-source monitoring

Collects publicly available freelance opportunities from multiple supported marketplaces and normalizes them into a common internal format.

AI-assisted analysis

Evaluates technical fit, project requirements, commercial signals and practical delivery risks before an opportunity reaches the decision stage.

Telegram delivery

Sends structured opportunity cards to Telegram so that the final decision and marketplace submission remain under human control.

Workflow

A practical automation pipeline

01 — Collect Public opportunity data is collected from supported sources.
02 — Filter Deterministic rules remove unsuitable or low-value projects.
03 — Analyze AI-assisted evaluation adds technical and commercial context.
04 — Deliver Relevant opportunities are delivered through Telegram for review.
Technology

Built as a production backend service

The project combines Python services, persistent workflow state, external integrations and automated server execution.

Backend stack

  • Python
  • SQLite workflow storage
  • HTTP/API integrations
  • Telegram Bot API

Operations

  • Linux production environment
  • Automated scheduled execution
  • Source failure isolation
  • Human-controlled final submission
Project approach

Automation without removing human control

The system automates repetitive discovery and analysis while keeping the final commercial decision and external submission manual. This provides useful automation without giving the system uncontrolled authority over client communication.
