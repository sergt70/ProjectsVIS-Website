Ansvarlig automatisering

VIS automatiserer gjentakende innholdsoppgaver samtidig som kontoeierskap, brukertillatelser og plattformkrav ivaretas.

  • Ingen innsamling av passord
  • Ingen uautorisert kontotilgang
  • Ingen garanti for visninger, rekkevidde eller inntekter
  • Ingen bruk til spam eller villedende aktiviteter
OAuth og databeskyttelse

Kontoer forblir under eiernes kontroll

VIS bruker offisielle OAuth-mekanismer fra støttede sosiale plattformer. Tilgangen begrenses til tillatelsene som kontoeieren har godkjent.

Ingen lagring av passord VIS ber ikke om og lagrer ikke passord for tilkoblede kontoer på sosiale medieplattformer.
Tillatelsesbasert tilgang Funksjoner utføres bare innenfor tillatelsene som ble godkjent under OAuth-autorisasjonen.
Kryptert tokenlagring OAuth-tokenene som brukes av VIS, lagres kryptert.
Tilkoblinger som kan tilbakekalles Kontoeiere kan tilbakekalle tilgang eller be om frakobling og sletting av tilknyttede data.
Viktig: VIS selger ikke personopplysninger og lover ikke garanterte visninger, rekkevidde, følgere, inntekter eller plattformgodkjenning.
